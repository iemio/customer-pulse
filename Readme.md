# Customer Behavior Data Analysis

End-to-end analytics project using Python, SQL & Power BI
A complete data analytics workflow demonstrating data preparation, SQL analysis, and interactive visualization—built to showcase real-world business intelligence skills.

## Project Highlights

-   Data Preparation & EDA → Python (Pandas, NumPy, Matplotlib)
-   Business Analysis → SQL (Complex queries, aggregations, customer segmentation)
-   Interactive Dashboard → Power BI (KPIs, trends, actionable insights)
-   Reporting → Documented findings and business recommendations

## Quick Start

```sh
git clone https://github.com/iemio/customer-pulse.git
cd customer-pulse
```

1. Run Customer_Shopping_Behavior_Analysis.ipynb for data cleaning & SQL loading
2. Execute customer_behavior_sql_queries.sql for business insights
3. Open customer_behavior_dashboard.pbix in Power BI
